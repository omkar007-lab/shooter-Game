## 🚀 Introduction
Welcome to **Shooter Game**, an exciting 2D side-scrolling shooter game built with Python and Pygame. Navigate through challenging levels, defeat enemies, and collect power-ups to enhance your gameplay experience.

## 🎮 Features
- **Multiple Levels**: Progress through various levels with increasing difficulty.
- **Diverse Enemies**: Face different types of enemies, each with unique behaviors.
- **Power-Ups**: Collect health packs, ammo, and grenades to aid your survival.
- **Stunning Visuals**: Enjoy detailed backgrounds and smooth animations.
- **Immersive Audio**: Experience the game with background music and sound effects.

## 🛠️ Installation
Follow these steps to set up the game on your local machine:

1. **Clone the repository**:
   ```sh
   git clone https://github.com/yourusername/shooter-game.git
   cd shooter-game

2.  Create a virtual environment:
python3 -m venv venv

3. Activate the virtual environment:

On Windows:

venv\Scripts\activate

On macOS and Linux:
source venv/bin/activate

4. Install the dependencies:

pip install -r requirements.txt

🚀 Usage
1. Run the game:
   python3 game.py
2. Controls:

A: Move left
D: Move right
W: Jump
SPACE: Shoot
Q: Throw grenade
ESC: Quit the game
📂 Project Structure
game.py: Main game script.
audio: Directory containing sound effects.
img: Directory containing game images.
levels/: Directory containing level data.
